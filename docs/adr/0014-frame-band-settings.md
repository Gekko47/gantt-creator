# ADR-0014 — Versioned frame and title settings

- **Status**: Accepted
- **Date**: 2026-09-25
- **Context**: R3.5 requires a populated title and a separately configured period-label format, but schema v1 initialised `ChartTitle` blank and contains no period-format key. The VeryHidden worksheet is not a user editor; valid user changes require an approved settings dialog. Adding a setting changes the exact catalogue key set and hash.
- **Decision**: Initialisation writes `ChartTitle="Gantt Chart"`. `ShowTitle=true` always emits the populated band; only `ShowTitle=false` hides it. `ChartTitle` remains nonblank and user-editable through an approved settings dialog. Add `PeriodLabelFormat` with closed values `MM`, `MMM`, `Quarter`, and `Year`, default `MMM`. Compatibility is closed: `Month` permits `MM`/`MMM`, `Quarter` permits `Quarter`, and `Year` permits `Year`. Advance workbook schema version to 2. Schema-v1 repair is explicit; it adds the missing key, replaces only an invalid legacy blank title with the default, preserves valid user values, and never changes the visible worksheet.
- **Consequences**: R3.5 can consume a fully typed and validated frame/band request. New settings are deterministic and culture-independent. Existing schema-v1 workbooks require the already-approved explicit repair workflow before refresh. The user-facing title editor is a separate downstream UI work item and is not part of Core-only R3.5.
- **Alternatives considered**: Keep a blank title and emit an empty band (rejected because the product requires populated visible titles); infer format from locale or `TimeScale` alone (rejected because the entity guide requires a setting); add an unrestricted format string (rejected because it permits ambiguous and invalid scale/format combinations).

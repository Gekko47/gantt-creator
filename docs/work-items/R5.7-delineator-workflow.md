## Design decisions (behavioural)

- **D1 — The dialog is §24's field list exactly.** Date, Label, Label
  Position, Line Style, Colour, Thickness, Visible; confirmation adds
  one visible table row with a generated stable ID (R2.8's inserter
  reused); cancel writes nothing (**positive test**).
- **D2 — Edit reuses the mutation adapters.** Editing writes the
  delineator row's cells (bulk, exactly the changed cells); `Start`
  validates within/on the plot range with an actionable refusal.
- **D3 — Delete is the first confirmed destructive command.** The
  R2.7a confirmation (count-only, safe default, no-undo warning per
  its approved Option) precedes the row deletion; the guard runs
  first; the live gate records the exercise (discharging R2.7a D6).
- **D4 — Ignored-field warnings surface.** Populated `Finish`/
  `LaneId`/`StackIndex` on a delineator produce the R2.5
  `NotUsedByType` warnings through the R5.8 surface when it lands;
  the dialog never silently strips them.

## Outcome

Preserve blank, value, Excel-error, and unsupported cell states in a neutral typed Core DTO.

## Decisions

- `GanttCellState`: `Empty`, `Value`, `ExcelError`, `Unsupported`.
- `GanttCell<T>` carries state, typed value, and optional neutral Excel error code.
- Known installed-PIA error integers map to named codes; future integers map to `Unknown`, never null.
- Core never references COM/XlCVError.

## Scope and tests

New Core state/cell/error types; update `ExcelCellConverter`, `GanttRowDto`, and `ExcelGanttTableReader`; adapt direct consumers mechanically. Core tests pin every known error and unknown future error. Office contract and live tests distinguish blank/error and preserve row order.

Checklist: A, C, F, G, I. Office gate: Required.

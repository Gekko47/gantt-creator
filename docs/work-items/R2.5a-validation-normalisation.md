# Work item — R2.5a

> **Guide status**: Approved Tier A, 2026-09-23. Implemented; verification evidence recorded below. Follow [`IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md) and [`../GanttCreator_R2_Implementation_Plan.md`](../GanttCreator_R2_Implementation_Plan.md).

## Outcome

Make validation the one deterministic normalizer from neutral cells to valid `GanttEvent` objects.

## Decisions

1. Relevant Excel errors and unsupported values are blocking.
2. A populated irrelevant field warns once and normalises to null without a second format error.
3. Optional-but-relevant fields validate when populated.
4. Critical Interval parents must be valid, mapped span events, and the Critical Interval parent relationship must be acyclic.
5. Geometry remains outside R2; R3.8 owns clipping/warnings.

Add stable codes for relevant Excel error, unsupported value, invalid parent, and parent cycle. Each new validator has a positive test. Preserve all-errors and deterministic severity/row/field/code order.

## Scope and tests

`GanttRowValidator`, `GanttValidationCodes`, Type applicability metadata, Core tests, and a Core architecture assertion that scene work consumes `GanttEvent`, not DTOs.

Checklist: C, F, G, I. Office gate: None.

## Stop conditions

- Geometry clipping is implemented in Core validation.
- A new blocking validator lacks a positive test.
- A warning-only row is excluded from events.

## Implementation evidence

- Added stable `CellContainsExcelError`, `CellValueUnsupported`, `ParentInvalid`, and `ParentCycle` codes.
- Added a state-aware one-pass classifier: relevant Excel errors and unsupported values block once; irrelevant populated/error cells warn once and normalize to null; blocked fields do not also emit required/format errors.
- Critical Interval parents now require a valid mapped span event, not merely a span Type; self-references and longer parent cycles are rejected before parent-validity reporting.
- Added a future-scene architecture guard: once `Core/Scene` exists, its source must not reference `GanttRowDto`.

- Office contract: 139/139 PASS.
- `verify-quick.ps1`: PASS, 11/11 steps, including packed-XLL publish and non-Office tests.
- No geometry or rendering changes were made. The Office `Value2` normalization helper is an interop read/preservation refactor with one-based and zero-based contract coverage.

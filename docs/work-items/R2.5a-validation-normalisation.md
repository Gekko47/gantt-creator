# Work item — R2.5a

> **Guide status**: Approved Tier A, 2026-09-23. Not implemented. Follow [`IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md) and [`../GanttCreator_R2_Implementation_Plan.md`](../GanttCreator_R2_Implementation_Plan.md).

## Outcome

Make validation the one deterministic normalizer from neutral cells to valid `GanttEvent` objects.

## Decisions

1. Relevant Excel errors and unsupported values are blocking.
2. A populated irrelevant field warns once and normalises to null without a second format error.
3. Optional-but-relevant fields validate when populated.
4. Critical Interval parents must be valid, mapped span events.
5. Geometry remains outside R2; R3.8 owns clipping/warnings.

Add stable codes for relevant Excel error, unsupported value, and invalid parent. Each new validator has a positive test. Preserve all-errors and deterministic severity/row/field/code order.

## Scope and tests

`GanttRowValidator`, `GanttValidationCodes`, Type applicability metadata, Core tests, and a Core architecture assertion that scene work consumes `GanttEvent`, not DTOs.

Checklist: C, F, G, I. Office gate: None.

## Stop conditions

- Geometry clipping is implemented in Core validation.
- A new blocking validator lacks a positive test.
- A warning-only row is excluded from events.

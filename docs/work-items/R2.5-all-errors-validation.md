# Work item — R2.5

## Outcome

`GanttCreator.Core` maps neutral `GanttRowDto`s into validated immutable `GanttEvent`s with all-errors validation: every blocking `Error` and non-blocking `Warning` is returned in deterministic `Severity → Row → Field → Code` order, and only valid rows become events. No rendering, no cell mutation.

### Decisions recorded here

- **D1 — Pure Core, no Office.** Validator takes `IReadOnlyList<GanttRowDto>` only; `CoreBoundaryTests` stays green.
- **D2 — First-canonical duplicates (U1).** First occurrence of an `Id` text is canonical; each later row with the same trimmed text gets `Error DuplicateId` and produces no event.
- **D3 — Description always optional (U2 revised).** No `DescriptionRequired` error for any type; blank maps to `null`.
- **D4 — Splitter/Spacer never lane-bound (U3).** `LaneId`/`StackIndex` present on Splitter/Spacer → `Warning NotUsedByType`, never required, never an error.
- **D5 — Custom deferred (U4).** `CustomActivity` blank `StyleKey` → `Error`; any trimmed non-empty `StyleKey` passes with no registry lookup; label-position and colour capability gates are skipped entirely for Custom (R2.9 owns them).
- **D6 — Procurement fill rejected (U5).** `FillColour` on `Hatch | Stroke` is always `Error ColourNotAllowedForType`.
- **D7 — SortOrder invariant non-negative (U6).** Blank → `null`; else Invariant-culture `int >= 0`, otherwise `Error BadSortOrder`.
- **D8 — Colours case-insensitive, normalised (U7).** Accept `^#[0-9A-Fa-f]{6}$`, store uppercase `#RRGGBB` on the event.
- **D9 — Deterministic order Severity → Row → Field → Code (U8 revised).** `Error` before `Warning`, then `RowNumber` ascending, then `Field` Ordinal, then `Code` Ordinal.
- **D10 — CriticalMilestone needs no parent (U9).** `ParentId` present on any non-`CriticalInterval` row → `Warning NotUsedByType`, retained (never geometry).
- **D11 — Milestone lane/stack optional (U10).** All four milestones: blank lane/stack allowed; when present must be well-formed.
- **D12 — Plot warnings deferred (U11).** No plot-range parameter, no clipping warnings; R5.1 owns the plot range.
- **D13 — Trim without rewriting.** Text compared Ordinal after `Trim()`; IDs and Type display names never case-folded (mirrors R2.1 D4 / R2.3 D2).
- **D14 — Never throw for bad rows.** Only `null` input list throws `ArgumentNullException` (with a positive test); every row-level fault is an issue.

## Exclusions

- Row error reporting/highlighting or any cell mutation (R2.6).
- Settings/style/metric tables, save/reopen (R2.7); add-row commands (R2.8); `tblGanttTypes` materialisation, `GanttCreator.TypeOptions` dropdown, catalogue hash (R2.9); repair/migration (R2.10).
- Plot-range clipping/out-of-range warnings (R5.1); style-registry existence checks (R2.9); label auto-resolution/collision; scene/geometry/rendering (R3+); Ribbon, PowerPoint, PNG; new NuGet packages; schema-version bump (stays v1).

## Acceptance tests

- **Automated** — `dotnet test tests/GanttCreator.Core.Tests` (all green incl. new `GanttRowValidatorTests`):
  - valid-16 matrix: one valid row per catalogue Type;
  - one positive `[Fact]`/`[Theory]` per validator (ID, Type, dates, lane/stack, parent, StyleKey, label, colours, SortOrder, duplicate, all-optional description);
  - all-errors: rows with ≥5 independent faults return every issue; bad rows excluded from `Events`;
  - ordering: exact `Severity → Row → Field → Code` sort asserted;
  - determinism: shuffled input (≥3 orders) yields identical `Issues`;
  - culture invariance under `tr-TR`.

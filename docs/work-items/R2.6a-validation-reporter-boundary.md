# Work item — R2.6a

> **Guide status**: Approved Tier A, 2026-09-23. Implemented; verification evidence recorded below. Follow [`IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md) and [`../GanttCreator_R2_Implementation_Plan.md`](../GanttCreator_R2_Implementation_Plan.md).

## Outcome

Keep Classic Notes as a replaceable reporter and enforce ADR-0008 guard-first ordering for every note mutation.

## Decisions

Inject `IWorksheetProtectionGuard`; return a typed protected-target report refusal before deleting or writing any note. No destructive confirmation is required. Core validation remains independent of Notes. User notes remain protected, and a later successful run repairs partial owned-note writes.

## Scope and tests

`ExcelGanttValidationReporter`, report outcome, `ValidateSheetCommand`, `ProtectionGuardFirstTests`, contract tests, AddIn tests, and a live protected-sheet test. Extend mutation discovery to note writes and register the reporter.

Checklist: C, F, G, I, J, K. Office gate: Required.

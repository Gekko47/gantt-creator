# Work item — R2.7b

> **Guide status**: Approved Tier A, 2026-09-23. Not implemented. Follow [`IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md), [`../GanttCreator_R2_Implementation_Plan.md`](../GanttCreator_R2_Implementation_Plan.md), and ADR-0009.

## Outcome

Materialise named-style default label position, allowed label positions, and colour-override capability so Custom Activity is fully defined without renderer fallback.

## Decisions

Append `DefaultLabelPosition`, `AllowedLabelPositions`, and `ColourCapability` to `tblGanttStyles`. Built-in rows project from their owning Type contract; user rows must validate all three explicitly. Schema remains 1 because configuration v1 was not shipped before R2.7. Old development workbooks are pre-release drift.

## Scope and tests

Core style preset/catalogue/hash; Office writer/reader; Core, contract, and live save/reopen tests. Update ADR-0007, architecture, entity guide, and R2.9 prerequisites.

Checklist: C, D, F, G, I, J, K. Office gate: Required.

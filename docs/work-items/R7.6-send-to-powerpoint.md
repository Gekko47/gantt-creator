## Design decisions (behavioural)

- **D1 — One command, the full pipeline.** Composition → staging →
  grouping → copy (verified formats) → attach/start resolution →
  paste (validated) → position (once) → cleanup — pinned order via
  the fake ports; concise count-only success ("Sent N shapes to the
  active slide"); each typed failure → one actionable message.
- **D2 — Ownership assertions are tests, not hopes.** The command
  tests assert: no `Save`/`SaveAs`/`Close`/`Quit` operation ever
  appears in the observed sequence (**positive test** injecting a
  would-be save path); only owned proxies released; the user's
  presentation object set unchanged except the pasted group.
- **D3 — A failed transfer never costs user data.** Excel staging
  cleaned (R6.5); PowerPoint untouched on failure (R7.5); state
  restored (R4.2 scope wraps the whole command).

## Acceptance tests

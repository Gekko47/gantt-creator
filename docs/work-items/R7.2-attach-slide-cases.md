## Design decisions (behavioural)

- **D1 — The matrix is closed and typed.** Cases: PowerPoint running
  (attach) vs not running (start per policy); presentation open and
  editable vs protected vs none; slide active vs missing. Each maps
  to exactly one typed outcome (proceed-with-context, or a named
  refusal the command translates to one actionable message).
- **D2 — The user-visible policy.** Starting PowerPoint (when none
  runs) and creating a new presentation (when the button contract
  says so) are user-visible choices — the policy text and its surface
  (an option or a per-run dialog) are fixed with the human at
  Tier-A upgrade; defaults recorded in the ADR space of R7.6.
- **D3 — Never hidden mutation.** Starting PowerPoint or creating a
  presentation is announced (never silent); attaching never alters
  the user's session state beyond the transfer itself.

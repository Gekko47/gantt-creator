## Design decisions

- **D1 — Dropdown mechanics.** Workbook-scoped defined name
  `GanttCreator.TypeOptions` whose `refersTo` covers exactly the active
  display-name cells of `tblGanttTypes` on `_GanttCreatorConfig` — no
  blank tail cells (entity guide rule). The `Type` column body of
  `tblGanttData` gets `xlValidateList` with
  `Formula1 = "=GanttCreator.TypeOptions"`, error style stop, applied to
  the whole current body (existing rows). Appended-row propagation is
  **unknown until probed**: if `ListRows.Add` does not inherit column
  validation, the materialiser's apply step is re-run by R2.8's command
  after insertion (small extension there; record the probe result).
- **D2 — Validation stays authoritative; dropdown is convenience.**
  R2.5's `UnknownType` blocking error must still fire for pasted or
  typed unknown values. A contract test re-asserts this after the
  dropdown exists (in-cell validation never becomes the only gate).
- **D3 — Registry-aware validation (the R2.5 U4 deferral).** New pure
  `GanttStyleRegistry` built from `tblGanttStyles` rows (via R2.7's
  reader): known style keys + per-style allowed label positions and
  colour capabilities. `GanttRowValidator` gains an overload taking the
  registry; without it (null) R2.5 behaviour is unchanged. New code
  `StyleKeyUnknown` (blocking — an unknown key on any type is a data
  error; the renderer must never fall back silently); `Custom Activity`
  gates fire from the style's capabilities reusing the existing
  `LabelNotAllowedForType` / `ColourNotAllowedForType` codes with
  registry-derived allowed sets (no new codes where existing ones carry
  the meaning).
- **D4 — Hash gate on materialise.** Before writing/refreshing the
  name, verify `tblGanttTypes` content matches `EntityTypeCatalog` via
  the R2.7 catalogue hash; a mismatch is a typed refusal pointing to
  repair (R2.10) — never a silent rewrite (that would mask drift).
- **D5 — Pipeline order.** `ValidateSheetCommand`: read rows → read
  style registry (typed refusal if config sheet/tables missing) →
  validate with registry → report (R2.6 reporter unchanged; it already
  surfaces any code generically).

## Design decisions (behavioural)

- **D1 — Scale choices are the closed set** month/quarter/week
  (§5/§6); any other value is a typed validation error, not a
  fallback. The `Year` scale is retired: the upper band is fixed as
  the year, so a `Year` lower band would duplicate it. A stored
  `Year` is refused rather than silently coerced, and it is
  compatible with no format.
- **D2 — Plot margin is a horizontal page margin applied to both
  sides of the layout width** (§8): the usable plotting area is
  `layoutWidth - 2 x margin`. It is subtracted from the width budget,
  never from the measured text panel, so it cannot resize a user's
  column (R4.7H D3). The margin is resolved once from the `Margin`
  (preset) and `MarginCm` (custom cm) settings.
- **D3 — The margin is a Windows-default preset set plus a custom
  value.** The three presets are the Windows/Excel horizontal
  defaults authored in centimetres: Narrow 0.635cm, Normal 1.78cm,
  Wide 2.54cm. `Custom` carries a user value through the companion
  `MarginCm` setting. An out-of-range custom cm is clamped at render
  time (never negative/unbounded); the reader refuses such values on
  read so the workbook is repaired.
- **D4 — Plot Width is a read-only display.** It is computed by
  `PlotGeometryResolver.MeasurePlotWidth` and equals the plot width
  the resolver would hand the scene. No preset = no display. The
  disabled Width box reads this; it MUST equal the width `TryResolve`
  derives, or the displayed figure and the rendered plot drift.

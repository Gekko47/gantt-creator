headers, bands, and page-width behaviour in Excel.

## Design decisions (behavioural)

- **D1 — Scale choices are the closed set** month/quarter/year (§5/§6);
  any other value is a typed validation error, not a fallback.
- **D2 — Page-width layout resolves the configured chart width** from
  the page setup of the active sheet (measured via the R4.1 adapter
  world; the builder consumes a resolved width, never measures).
  Exact page-width semantics (orientation, margins) are fixed at the
  Tier-A upgrade after a live probe; deviations recorded here.
- **D3 — Snapshots per choice.** The test matrix pins the full band
  geometry for {month, quarter, year} × {page-width, explicit} —
  header heights, band boundaries, label suppression at narrow
  widths, and the plot-left position for each.

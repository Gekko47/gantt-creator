## Design decisions

- **D1 — Bar geometry (§12).** `left = DateToX(Start)`,
  `durationDays = Finish.DayNumber - Start.DayNumber + 1`,
  `width = durationDays * DayWidth`, and `right = left + width`; the bar
  rect is vertically centred on the slot centre with the resolved activity
  height. `Finish` is never incremented. Bars go to z-layer 40 with
  `ActivitySubtypePriority` ordering (R3.2).
- **D2 — Clipping (coordinate rules).** Bars crossing the plot clip at
  `PlotBounds.Left/Right` (the bar rect, never the dates); a span
  wholly outside emits no bar and one warning per event; partial
  clipping emits one warning per event. Warnings are `SceneWarning`s —
  the §26 indicator layer consumes them later; nothing is silently
  dropped.
- **D3 — `ITextMetrics` port (the architecture's one service).**
  `Measure(text, typographyToken) → TextMeasurement` (width, height in
  pt). Core ships `FakeTextMetrics` (deterministic table-driven fake,
  version-pinned for tests); the live Excel implementation is a Phase 4
  adapter over the same port. The scene stores resolved label bounds;
  renderers never call `ITextMetrics`.
- **D4 — `LabelPlanner` (§22 exactly, as amended by ADR-0015).** Position
  precedence: explicit row value → named-style default → `Auto`
  candidates (Right → Left → Inside for spans) → widest-gap truncation
  fallback + one warning. Candidate
  geometry per §22's table (`LabelGapPt` offsets, vertical centring,
  Inside only when measured text fits). Acceptance: containment in
  allowed chart bounds, no intersection with registered foreground
  shapes or higher-priority labels (Inside may occupy its own parent).
  Placement priority across entities exactly §22's list; within a
  priority: lane, stack, `SortOrder`, stable ID. Deterministic on every
  refresh — no side-flipping between runs.
- **D5 — Labels are scene text primitives** at layer 70 with
  role-derived IDs (`<rowId>:label`), consuming resolved token colours;
  delay-event text colour switches `DelayText` (inside) ↔
  `DefaultText` (outside) per §17.
- **D6 — Overflow policy v1.** No automatic font shrinking; external
  labels cap at `MaximumExternalLabelWidthPt` with ellipsis + one
  warning, and the ADR-0015 widest-gap fallback truncates with the same
  single-character `…` to the measured gap width. The ellipsis must never
  split a surrogate pair. **Wrap is not defined by any approved document —
  stop-point: if the product owner wants wrapping, it needs an
  entity-guide amendment first.**

## Implementation steps (in order)

1. `ITextMetrics` + `TextMeasurement` + `FakeTextMetrics` (D3; XML docs
   citing the architecture rule).
2. `SpanBarBuilder` (D1/D2) with clip-warning emission.
3. `LabelPlanner` (D4/D5/D6): candidate generation, acceptance checks,
   the §22 priority list, fallback + warning.
4. Tests — **before/within/crossing/after-range geometry**: bar
   entirely before range → no bar + warning (**positive test**);
   crossing-left/right → clipped rect + warning; wholly within → exact
   rect; one-day width pin; slot-centring pin; subtype z-order pin
   (baseline behind planned behind actual; procurement above its base
   family; custom; delay). Label tests: every §22 position pin;
   explicit-beats-style-beats-Auto precedence; `Auto` Right → Left →
   Inside order, including that a fitting `Left` beats a fitting `Inside`
   (**positive test**); Inside rejected when text does not fit (**positive
   test**); collision with a registered higher-priority label rejects
   the candidate (**positive test**); widest-gap fallback places the
   label at the widest measured gap, truncates with `…` to the measured
   width, emits exactly one warning, breaks equal-width ties by the
   `Auto` order, and suppresses the label with one warning when no gap
   holds even an ellipsis (**positive tests**); fallback is stable
   across repeated planning runs; ellipsis at
   `MaximumExternalLabelWidthPt` (**positive test**); ellipsis never
   splits a surrogate pair (**positive test**); the delay event resolves
   its style default `Inside` once and never re-enters it, escaping to
   `Right` then `Left` (**positive test**); delay-event
   inside/outside colour switch; Unicode/long/blank text; determinism
   (≥3 shuffles → identical label plan).
5. Docs: REPO-MAP (Core row gains `ITextMetrics`), STATUS, status line.
   One commit: `feat: R3.6 …` — Checklist: A, B, C, E, G, I.

## Outcome

A scene's declared `ChartBounds` is the same rectangle as the
`chart:background` primitive it contains, so a chart can no longer claim bounds
its own content does not have.

## Context

R3.12 landed a `SceneValidator` whose `LabelOutsideChart` finding fired against
a scene the R3.12 orchestrator had itself built. The first diagnosis — "the
frame builder does not check that its bands fit" — **was wrong**, and this item
records the corrected one so it is not re-derived.

Entity guide section 2 states the contract plainly: *"`ChartBounds` is the union
of the title, data panel, time headers, and plot plus `ChartOuterPaddingPt`."*
So `FrameBandsBuilder` computing its own chart bounds is **correct**, and it must
not be constrained by a caller's value.

The fault was in `SceneBuilder`: it created the scene with the **caller's**
`chartBounds` while `frameResult.Geometry.ChartBounds` sat unused one line
above. Two sources of truth, one ignored. The R3.12 fixture only passed because
its `ChartBounds` happened to enclose the derived one, and the fixture had been
fudged — panel at `y=20`, plot at `y=110` — purely to keep the bands inside the
declared chart. That fudge concealed the disagreement.

## Design decisions

- **D1 — Chart bounds are derived, never supplied.** Entity guide section 2
  defines them as a union, so a caller-supplied chart bounds is a second,
  contradictory source. Option A was chosen over repurposing the property as a
  snap-to constraint (which would invent a contract the guide does not state) and
  over keeping it advisory (which is the bug). Removal is cheap now because
  `SceneBuilder` still has no production consumer.
- **D2 — The dead guard is removed, not kept.** Once chart bounds are derived,
  the plot is inside them by construction, so `PlotOutsideChart` can never fire.
  AGENTS.md treats an unreachable validator as a defect, so the member and its
  positive test are deleted rather than left vacuous.

## Implementation steps

2. Create the scene with `frameResult.Geometry.ChartBounds`.
3. Tests: `The_declared_chart_bounds_equal_the_emitted_chart_background` and

## Scope

- The freeze: every dependency version pinned/locked (no floating
  ranges anywhere); the lock files verified by locked restore.
- Third-party notices: a complete notices artifact (each package +
  licence text/reference; the SkiaSharp font story per R8.2a's ADR
  cross-referenced).
- The SBOM: generated, validated (schema + completeness vs the
  inventory), and committed/published per the release gate.
- Vulnerability scan + licence check results recorded.
- The inventory cross-check: packaged files ↔ SBOM ↔ approved list
  (a mismatch fails — **positive test**: an injected extra binary
  fails the check).
- `docs/REPO-MAP.md`, `docs/STATUS.md`, status line.

## Exclusions

- No version upgrades in this row (freeze, not churn — an upgrade is
  its own reviewed change); no new dependencies; no notices
  hand-written from memory (generated + reviewed).

## Design decisions (behavioural)

- **D1 — Frozen means enforced.** Locked restore + a no-floating-range
  assert (the repo's central-package discipline) prove the freeze;
  the R9.8 network guard re-runs against the final set.
- **D2 — SBOM ↔ inventory is a test, not a document.** The
  cross-check is automated (missing/extra packaged file fails).
- **D3 — Notices are generated then reviewed.** Generator output +
  human review; licence texts included/referenced per the release
  gate.

## Acceptance tests

- **Automated**: locked restore green; no-floating-range assert;
  SBOM schema validation + inventory cross-check (**positive test**
  for a mismatch); vulnerability/licence scan results recorded.
- **Office host (Required)** — the packaged native/runtime inventory
  confirmed on the installed candidate (files present as listed;
  nothing extra); record host builds.

## Stop conditions (item-specific)

- A floating version range is found → stop; pin it (the dependency
  policy) — the freeze cannot ship with ranges.
- A packaged file is absent from the SBOM (or vice versa) → stop;
  the inventory is wrong somewhere — find it.

## Risk and rollback

Main risk: stale notices — D3's regenerate-and-review step keeps them
current at the freeze. Rollback: `git revert`.

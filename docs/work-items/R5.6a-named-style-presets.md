# Work item — R5.6a

> **Guide status**: Binding contract, added 2026-09-23 by the R2 findings reconciliation. Upgrade to Tier A at Phase 4 exit.

## Outcome

Create, rename, and delete approved user named-style presets through an offline Ribbon dialog, including the explicit label/colour capability fields required by ADR-0009. Built-in keys cannot be deleted; custom styles preserve portable offline configuration and feed Custom Activity validation.

## Dependencies and exclusions

Depends on R2.7b, R2.9, R2.10, R4.6, and R5.6. No Office theme inheritance, arbitrary code, shape mutation, or renderer-specific fallback.

## Acceptance contract

Command/contract tests cover unique keys, every capability field, cancel-before-write, built-in protection, save/reopen, and Custom Activity consumption. Office gate compares the configured style with live Refresh output.

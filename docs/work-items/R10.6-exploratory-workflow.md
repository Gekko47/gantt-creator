## Scope

- The exploratory run: a human, on the installed candidate, from a
  blank workbook through the full workflow (initialise → author rows
  via commands/dropdown → Refresh → copy editable → paste to
  PowerPoint → ungroup/edit → PNG export → verify).
- Issue records: each finding gets an entry (symptom, repro, severity,
  decision: fix now / route to a row / defer with a KNOWN-LIMITATIONS
  row + owner + expiry).
- Fix linkage: every fix references the finding; every defer links
  its limitation row.
- `docs/REPO-MAP.md`, `docs/STATUS.md`, status line.

## Exclusions

- No new features as fixes (fixes route to their owning rows or a new
  work item); no unreviewed deferrals (each needs the decision
  trail); no agent-run substitution for the human pass (the gate is
  human by definition).

## Design decisions (behavioural)

- **D1 — Exploratory means unscripted.** The outline is a checklist,
  not a script; the human also tries adjacent paths (mis-typed values,
  odd selections, cancelled dialogs) and records friction, not only
  failures.
- **D2 — Every finding is dispositioned.** Fix / route / defer — no
  finding evaporates; defers land in KNOWN-LIMITATIONS with the
  metadata.
- **D3 — The exit demonstration rides this run.** The non-developer
  clean-machine demonstration (the Phase 10 exit) is executed and
  recorded here with host builds.

## Acceptance tests

- **Office host (Required, human)** — the exploratory run + exit
  demonstration; the finding log with dispositions; the
  KNOWN-LIMITATIONS updates.

## Stop conditions (item-specific)

- A finding invalidates a product invariant → stop; that is a
  scope-change/ADR path, not a quick fix.
- A deferral cannot name an owner/expiry/replacement gate → stop;
  the KNOWN-LIMITATIONS contract requires them.

## Risk and rollback

Main risk: findings sprawling without disposition — D2's
no-evaporation rule is the guard. Rollback: `git revert` (docs-only
unless fixes route elsewhere).

## Definition of done

From `AGENTS.md` + `docs/08-TEST-CHECKLIST.md` sections **G, I**: the
run + demonstration recorded; every finding dispositioned; limitation
rows updated; REPO-MAP/STATUS current.

## Design decisions (behavioural)

- **D1 — Data-intact is the assertion.** Every fixture asserts the
  worksheet data matrices are unchanged across recovery (success or
  failure), alongside the R2.10 detection/repair pins.
- **D2 — Version-mismatch paths.** Older-version migration recovers
  (preserving user styles/settings per R2.10 D3); newer-version
  refuses with the update-the-add-in message (R2.10 D1) — both
  verified end to end here.
- **D3 — Failure paths leave data intact.** A refused/failed recovery
  still leaves the workbook usable and the data unchanged.

## Acceptance tests

  assertions (**positive tests** per refusal path).
- **Office host (Required)** — live: open a corrupted synthetic

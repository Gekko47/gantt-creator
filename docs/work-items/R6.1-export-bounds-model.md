## Design decisions (behavioural)

- **D1 — Two selections, one bounds rule.** Chart-only = the scene's
  `ChartBounds` (§1 union rule) without the data-panel contribution;
  table-plus-chart = the union including the panel grid bounds. Both
  exclude whitespace outside the union; both carry the grouped-export
  bounds the later grouping step will verify against.
- **D2 — Refusals, not empties.** An empty visible table with
  table-plus-chart selected refuses with the actionable message
  (aligned with §1 "an empty data table … is not a valid export");
  invalid bounds refuse before any composition.
- **D3 — The model is the contract for R6.3's group-bounds check and
  Phase 8's crop bounds** — recorded so those rows consume, never
  recompute.

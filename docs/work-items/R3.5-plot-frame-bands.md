## Design decisions

- **D1 — §1 union geometry.** `ChartBounds` = union(title band when
  present, panel width, year+period bands, plot) expanded by
  `ChartOuterPaddingPt` on all sides; the frame rect + major border
  follows the final bounds exactly. Zero/invalid dimensions refuse
  (typed outcome).
- **D2 — Measured width is an input.** The builder never measures; it
  consumes `panelWidthPt` (and later measured cell bounds from R3.11's
  world). Pure Core tests inject fixture widths; the live measurement
  belongs to Phase 4/5 adapters.
- **D3 — Title band policy.** Band present iff `ShowTitle = true`;
  blank `ChartTitle` keeps the band with no text entity (the guide's
  "blank suppresses the title band only when `ShowTitle=false`"
  read conservatively); overflow ellipsis + warning; **flagged for
  product-owner confirmation at review** (§2's sentence admits a second
  reading).
- **D4 — Band sequences.** `BandSequence` enumerates year periods and
  the scale's periods (month/quarter/year per the `TimeScale` setting)
  across the inclusive plot range, clipped at both edges; each band
  records its visible width so §5/§6/§7 suppression/parity rules are
  testable in isolation.
- **D5 — Layers exactly per the z-order table.** Background 0;
  alternating bands 10; grid/lane separators 20; year/period headers
  80; title 90. Grid lines deduplicate by X with the year/major line
  winning (§8).

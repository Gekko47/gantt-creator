# Work item — R11.1 core refactor remediation

> Created 2026-11-24 from the read-only code review of `src/GanttCreator.Core`.
> One finding per commit. Owner rulings of 2026-11-24 are recorded under
> "Owner decisions". This item is subordinate to `AGENTS.md`, the architecture,
> the entity guide, and the ADRs.

## Outcome

The eight ranked Core findings are closed with behaviour-preserving refactors,
except the row-override colour grammar, which the owner ruled is a design
mismatch: row overrides accept `#RRGGBBAA` exactly as the style and theme paths
do. Every step is covered by the existing Core test suite, with new positive
tests where behaviour changes.

## Owner decisions

- **Colour grammar (2026-11-24):** accepting `#RRGGBBAA` on style and theme but
  rejecting it on per-row overrides is a design mismatch. Row overrides must
  accept it. If neither the Office shape writer nor the Raster renderer honours
  alpha, stop and report rather than accept a value that is silently ignored.
- **Preset lookup failure (2026-11-24):** keep the fail-fast throw for a
  code-owned preset, but replace the bare LINQ `First()` failure with a message
  that names the missing style key.

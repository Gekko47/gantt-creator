## Design decisions (behavioural)

- **D1 — Errors are first-class accessible surfaces.** Every user
  message/dialog carries the same label coverage as the Ribbon
  (resource-backed, screen-reader-visible where the host exposes it).
- **D2 — High-contrast safety is tested, not assumed.** Dialog and
  message colours remain readable under Windows high-contrast themes
  (the live review) — no hard-coded pairs that break.
- **D3 — Keyboard-only paths.** Every error surface is dismissible
  and every action reachable by keyboard (Esc/Enter/Tab semantics
  pinned in the review).
- **D4 — Host capability limits are recorded.** Anything the host
  cannot expose to assistive tech is documented as a known
  limitation with the evidence, never silently skipped.

## Acceptance tests

- **Automated — `dotnet test tests/GanttCreator.AddIn.Tests`**:
  resource-backing (no bare literals — a source-scan contract);
  label/metadata pins; offline links.
- **Office host (Required)** — live: keyboard walkthrough,
  high-contrast theme run, screen-reader pass over a provoked error;
  record findings (incl. host limits per D4) and host builds.

the ownership rules for their COM proxies exist in `GanttCreator.Office`
— every proxy the add-in owns is tracked and released, and nothing it
does not own is touched — pinned by fake-adapter lifecycle and

## Design decisions (behavioural)

- **D1 — Ports mirror the R4.1 discipline.** Narrow, primitive-typed,
  Moq-able via seams; `IPowerPointTransfer` is the architecture's
  named surface; the adapter owns only the proxies it creates.
- **D2 — Ownership is explicit and testable.** The tracker records
  every owned proxy; release happens in reverse order through the
  tested ownership helper; unowned PowerPoint objects (the user's
  application, presentations, slides) are never released or
  terminated.
- **D3 — STA only.** All adapter members document the STA/main-thread
  requirement; no async wrappers.

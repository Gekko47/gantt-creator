## Design decisions (behavioural)

- **D1 — Consume, never recalculate.** The renderer walks the scene's
  ordered primitives; geometry converts through the single raster
  mapping (architecture formula); it never re-derives dates, lanes,
  colours, or order (contract-tested the R4.3 D4 way).
- **D2 — Z-order is the scene's.** Primitives draw in scene order
  back-to-front; no renderer-side sorting beyond that order; a
  contract test pins the draw sequence.
- **D3 — Clipping per the scene.** Clipped primitives draw their
  clip (the scene already clipped); the renderer applies the canvas
  clip at the scene bounds — no renderer-side policy.
- **D4 — Deterministic re-render.** Two renders of the same scene +
  width produce byte-identical pixels (the determinism pin; golden
  comparisons build on it).
- **D5 — Native assets.** The chosen SkiaSharp version's native
  binaries are part of the add-in payload — the packaging row (R9.5)
  inherits this requirement; record it here so it cannot be
  forgotten.

## Design decisions (behavioural)

- **D1 — Success = verified format, not a non-throwing call.** The
  copy stage reports success only when the expected Office drawing
  format(s) (from the spike evidence) are present; a silent `Copy()`
  return proves nothing (**positive test**: format absent → typed
  failure, no success reported).
- **D2 — Clipboard-unavailable is a distinct failure.** The
  compatibility-matrix failure row ("clipboard unavailable") is a
  typed refusal with an actionable message (not an exception, not a
  silent pass) — injection-tested.
- **D3 — Verification is immediate and bounded.** Format enumeration
  happens right after copy (before cleanup per the ADR ordering); no
  polling loops, no sleeps (bounded, deterministic).

## Implementation record

Status: **implemented 2026-11-18.** The verified copy fills the R6.5 seam; no command is
exposed (R6.8's row).

- `StagedShapeCopier` + `StagedCopyRefusal` (Office) implement copy-then-verify: the copy goes
  through `IShapeCopyPort`, the observation through `IClipboardFormatReader`, and success is
  reported only when both `Excel 2007 Internal Shape` and `Art::GVML ClipFormat` are present
  (the measured pair, never "any format"). `ClipboardUnavailable` and `ExpectedFormatAbsent`
  are distinct typed refusals; the busy path carries the reader's token plus an actionable
  sentence.
- `ExcelShapeCopier` (guard-first, ownership by recomputed `ShapeStagingTag.ForStagedName`,
  `Shape.Copy` on the proven proxy) and `WindowsClipboardFormatReader` (the `user32`
  `EnumClipboardFormats` route the R6.7 spike measured with; typed failure; internal virtual
  seams) are the live adapters. `StagingCopyResult` gained `StagedCopyRefusal? Refusal` and
  `ShapeWriteRefusal? PortRefusal` additively; the R6.5 factories and 14 lifecycle facts are
  unchanged.
- **Two recorded deviations from the plan, both forced by existing gates:**
  (1) the shared resolution/ownership proof is a public abstract base
  (`StagingShapeAdapter`), not a composed internal locator — a composed helper would bypass
  the R6.4 test subclasses' `internal virtual` seam overrides, and inheritance keeps all 24

  `ExcelShapeCopier` is classified **read-only** in `ProtectionGuardFirstTests`, not in the

  `GanttRefreshOrchestrator` precedent for a read-only-classified file that consults

- The Office project gained `AllowUnsafeBlocks` (documented in the csproj) because
  `[LibraryImport]`'s generated marshalling emits function pointers; no unsafe code is
  written by hand, and no package was added.

> **Guide status**: Approved Tier A, 2026-09-23. Not implemented. Follow [`IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md) and [`../GanttCreator_R2_Implementation_Plan.md`](../GanttCreator_R2_Implementation_Plan.md).

## Outcome

Initialise adopts only a pristine worksheet. A cell-empty worksheet containing non-cell user state is preserved and the create-new-sheet path is used.

## Decisions

1. Adoption requires `CountA(UsedRange) == 0` and an `A1`-only used range.
2. Shapes, legacy comments/notes, threaded comments, worksheet/workbook names, tables, pivot tables, query tables, or hyperlinks make the sheet non-pristine.
3. Non-pristine does not mean refusal: preserve the sheet and create `Gantt Data` after it.
4. Existing config/table conflicts and protection remain typed zero-mutation refusals.

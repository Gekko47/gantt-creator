## Design decisions (behavioural)

- **D1 — Counters, not impressions.** The harness records exact
  counts: Excel/PowerPoint process PIDs alive at end vs the owned
  set (zero unowned orphans); shapes per slide (cumulative only
  where intended); the proxy-counter trend (flat within a recorded
  tolerance across iterations 1→25 — the leak signal); timings
  (median + max, recorded).
- **D2 — Cleanup asserted every iteration.** Zero staging residue
  after each of the 25 transfers (not just at the end); a residue at
  any iteration fails the run loudly.
- **D3 — Exit evidence.** The demonstration run recorded with host
  builds; the matrix subset completed (slide sizes; the
  PowerPoint-side failure rows); the Phase-8 guides upgraded to
  Tier A with refresh dates; the manifest tiers updated. Note: the
  roadmap's Phase-8 note allows executing Phase 8 directly after
  Phase 4 **with one order-change ADR** — the default remains
  sequential.

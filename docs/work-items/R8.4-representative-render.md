## Design decisions (behavioural)

- **D1 — Human approval is the gate.** Every baseline image is
  human-reviewed before commit; the commit message states why each
  image is correct (test-strategy rule) — an agent never approves
  its own rendered output as a baseline.
- **D2 — Exact where geometry is exact.** Region tests assert exact
  pixels for hard geometry (frames, bars, grid, bands); the small
  perceptual tolerance applies only to text antialiasing, documented
  with the value.
- **D3 — Pinned rendering metadata.** Each baseline records renderer
  version, OS, culture, DPI, font family/version (per R8.2a), and
  antialias settings; the harness asserts the recorded metadata
  matches the run.
- **D4 — L4's closure evidence.** The first approved representative
  render + its baseline directory is L4's replacement gate; the
  KNOWN-LIMITATIONS row is re-dated/closed in the same change with
  the evidence link.

## Risk and rollback

Main risk: baseline brittleness across machines — mitigated by the
pinned metadata + the human-approved policy (baselines are
reference-machine artefacts). Rollback: `git revert` (baselines are
additive).

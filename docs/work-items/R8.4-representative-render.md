## Design decisions (behavioural)

- **D1 — Human approval is the gate.** Every baseline image is
  human-reviewed before commit; the commit message states why each
  image is correct (test-strategy rule) — an agent never approves
  its own rendered output as a baseline.
- **D2 — Exact where geometry is exact.** Region tests assert exact
  pixels for hard geometry (frames, bars, grid, bands); the small
  perceptual tolerance applies only to text antialiasing, documented
  with the value.
- **D3 — Pinned rendering metadata.** Each baseline records renderer
  version, OS, culture, DPI, font family/version (per R8.2a), and
  antialias settings; the harness asserts the recorded metadata
  matches the run.
- **D4 — L4's closure evidence.** The first approved representative
  render + its baseline directory is L4's replacement gate; the
  KNOWN-LIMITATIONS row is re-dated/closed in the same change with
  the evidence link.

## Step 0 outcome and close-out (2026-11-23)

- **Prerequisites verified**: R8.3 landed (text, hatch and dash goldens committed);
  ADR-0070 and ADR-0071 Accepted; the `Category=FontProbe` exclusion wired in
  `test-non-office.ps1`/`verify.ps1` and pinned by `ci-parity.Tests.ps1`; the
  golden-scene guards green.
- **Ratified widths** (owner, 2026-11-23): 29.7cm → 3508×1906; 45.16cm
  (Presentation 16:9) → 5333×2898; 36.12cm (Presentation 4:3) → 4267×2318;
  800px → 800×435; 2400px → 2400×1304. Preset arms derive their width from
  `SizePresets.WidthPt` at full precision; the pixel arms are the ratified
  literals.
- **Ratified storage** (owner, 2026-11-23): a SHA-256 digest of the exact BGRA
  buffer plus the human-review PNG and a metadata sidecar per width. The raw
  five-buffer set would total ≈142 MB and every regeneration would re-commit
  that size, so the buffers are not committed.
- **Fixture-typography ruling** (owner, 2026-11-23): the committed scene carried
  `FontFamily:null` on all 82 primitives (the R3.12 request defined no
  typography), so the R8.3 pinned-font renderer failed closed and no baseline
  could exist. The reference request's `LabelStyle` and
  `ReferenceSceneBuilder.FrameTheme` now carry the code-owned catalogue
  typography (Aptos; Body/Header/Year/Title sizes) and a text colour, and the
  golden scene was regenerated through its explicit route as a style-fields-only
  change (geometry unchanged).
- **F2 correction**: the byte round-trip guard already existed since R3.12
  (`The_golden_snapshot_round_trips_through_deserialization`); this row adds the
  member-wise structural arm
  (`The_committed_scene_deserializes_to_the_fixture_built_scene`), which catches
  a model field missing from the snapshot document — the direction byte identity
  cannot see because both serializations omit it.
- **Human approval** (2026-11-23): all five images approved as rendered. Two
  scene-contract outcomes are recorded rather than treated as renderer defects:
  the full-height `02/02/2026` delineator crosses the title row, and the
  fixture's deliberate same-date events cluster their labels.
- **Evidence**: representative suite 10/10; the reference-machine
  `Category=FontProbe` command 30/30; the targeted Core Scene namespace 793/793;
  Release build 0 warnings.

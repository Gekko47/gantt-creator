## Design decisions (behavioural)

- **D1 — The preview is delegated math.** Preview = `ExportSize`
  output for the current input; a pin asserts equality for a table of
  inputs (no second formula anywhere).
- **D2 — Validation is immediate and precise.** Invalid input
  (non-finite, out of range, over the safety limit) shows the
  actionable message naming the limit; the export action stays
  disabled until valid (**positive tests** per violation).
- **D3 — Unit switching is deterministic.** Changing unit without
  changing the numeric value does not silently convert (the number
  means "value in the selected unit" — the architecture's formulas);
  the preview updates accordingly — pinned.

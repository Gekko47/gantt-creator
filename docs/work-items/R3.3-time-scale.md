## Design decisions

- **D1 — Typed creation, explicit range.** `TimeScale.TryCreate(
  DateOnly plotStart, DateOnly plotFinish, double plotLeftPt, double
  plotRightPt)` returns `TimeScaleCreationOutcome`. Refusals: `StartAfterFinish`, `DefaultDates`,
  `NonFiniteOrDegenerateWidth`. `plotStart == plotFinish` is legal (a
  one-day plot). Never throws for routine bad input.
- **D2 — Day index, culture-free.** `dayIndex = date.DayNumber −
  plotStart.DayNumber` — no `DateTime`, no culture; leap days and year
  boundaries are correct by construction.
- **D3 — Start-of-day mapping and duration geometry.** `dayWidth = (rightPt − leftPt) / totalDays`, `totalDays = plotFinish.DayNumber − plotStart.DayNumber + 1`; `DateToX(date) = leftPt + dayIndex * dayWidth`. `DurationDays = Finish.DayNumber - Start.DayNumber + 1`; activity `left = DateToX(Start)`, `width = DurationDays * dayWidth`, and `right = left + width`. `Finish` is never incremented.
- **D4 — Point-event mapping.** Milestones and delineators use `DateToX(EventDate)` with no half-day offset and no duration-derived right edge. The plot’s supplied right boundary remains the exclusive geometry boundary for the inclusive plot range.

# R0.2 — Solution, project folders, and allowed project references

> Block 0, R0.2 from `docs/03-ROADMAP.md`. Builds on R0.1 (governance
> kit and repo scaffolding).

## Outcome

The solution (`GanttCreator.slnx`) loads with four production projects
and six test projects, all targeting `net10.0` or `net10.0-windows`.
`global.json` pins the SDK. `Directory.Build.props` enforces nullable,
warnings-as-errors, and central package management. The architecture test
prevents `GanttCreator.Core` from referencing Office, Excel-DNA,
SkiaSharp, clipboard, or any other infrastructure assembly.

## Scope

- `global.json` — pins SDK to `10.0.400` with `rollForward: latestFeature`.
- `GanttCreator.slnx` — solution file with `/src/` and `/tests/` folders.
- `src/GanttCreator.Core` — `net10.0`, no infrastructure references.
- `src/GanttCreator.Raster` — `net10.0-windows`, references Core.
- `src/GanttCreator.Office` — `net10.0-windows`, references Core.
- `src/GanttCreator.AddIn` — `net10.0-windows`, references Core + Office
  + Raster; `ExcelDna.AddIn 1.9.0`.
- `tests/GanttCreator.*.Tests` — one test project per production target.
- `tests/GanttCreator.Architecture.Tests` — `net10.0`, no
  ProjectReference; loads `Core.dll` by path and inspects references.
- `Directory.Build.props` — nullable, implicit usings, LangVersion 14,
  TreatWarningsAsErrors, analyzers, deterministic builds, central
  package management, SourceLink, NoWarn list for placeholder scaffolds.
- `Directory.Packages.props` — pins ExcelDna.AddIn 1.9.0,
  ExcelDna.Integration 1.9.0, ExcelDna.Interop 16.0.0.
- `tests/Directory.Build.props` — test-specific settings
  (EnforceCodeStyleInBuild=false for xUnit conventions).

## Risk and rollback

Risk: a forbidden assembly reference slips past the architecture test.
Mitigation: the forbidden-assembly list in `CoreBoundaryTests.cs` is
explicit and loaded by reflection, so any new reference to
`Microsoft.Office.*`, `ExcelDna.*`, `SkiaSharp`, etc. fails the test.
Rollback: `git revert <commit>`; the solution and projects go with the
revert.

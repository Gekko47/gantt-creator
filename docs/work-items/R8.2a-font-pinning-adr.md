## Design decisions (to be answered by the ADR — options with
recommendations)

- **Option A (recommended if licensing permits): bundle a
  redistributable font** so raster text and golden images are
  machine-independent — depends on licence evidence.
- **Option B: require the installed font** (Aptos-class) — simplest,
  but golden images depend on the reference machine's font version
  and a missing font must error clearly.
- **Option C: approved open fallback** with the fallback pinned and
  documented — only if A/B fail licensing or consistency tests.
- **D1 — Never silent substitution.** Whichever option wins, a
  missing/mismatched pinned font produces a clear error or the
  approved fallback path; R8.3's text rendering and R8.4's golden
  images test the chosen behaviour.
- **D2 — The probe is evidence.** The probe's exact resolved-font
  record (family, version, file path) is committed as evidence for
  the ADR and the golden-image pinning metadata.

## Design decisions

- **D1 — §9 formulas verbatim.** Distinct `StackIndex` values sort
  ascending and map to consecutive visual slots; `slotHeight = max
  resolved rectangle height or milestone size in that slot`;
  `contentHeight = topPadding + sum(slotHeight) + max(0, stackCount − 1)
  * StackGapPt + bottomPadding`; `laneHeight = max(LaneHeightPt,
  contentHeight)`; slot centre = lane top + top padding + preceding
  slot heights/gaps + half current slot height. Events are never
  compressed (growth only).
- **D2 — Deterministic input order.** Events order by (`SortOrder`
  value with a documented blank fallback, row order, stable `Id`);
  lanes appear in first-appearance order of that sequence. Rationale:
  `SortOrder` is the user's explicit tool, visible row order is the
  natural tiebreak, `Id` is the stable last resort (entity guide
  "lane, stack, sort order, then stable ID"). **If the product owner
  wants a different lane ordering (e.g. by lane name), that is an
  entity-guide gap — stop for a decision, do not invent.**
- **D3 — Splitter and spacer lanes.** A `Splitter` consumes one
  fixed-height lane (`SplitterHeightPt`, spanning data panel + plot,
  no date geometry); a `Spacer` consumes `SpacerHeightPt` with no
  foreground shapes. Both take their position in the lane sequence from
  D2's ordering like any other row.
- **D4 — Same-stack overlap is preserved, warned, never moved.**
  Events sharing a slot share its centre; deterministic z-order comes
  from R3.2's layer-40 rule; a non-blocking ambiguity warning is
  emitted (entity guide §9 Validation) through `SceneWarning`.
- **D5 — Shuffled-input proofs without a new dependency.** "Property
  tests" = xUnit `[Theory]` over ≥3 fixed shuffles plus seeded-RNG
  permutations (deterministic seed recorded in the test). No FsCheck —
  a new dependency needs human approval.
- **D6 — Defensive guards.** Builder rejects negative `StackIndex`
  (already blocked by R2.5 — defence in depth), null/empty inputs, and
  non-finite heights, each with a typed refusal and a **positive
  test**.

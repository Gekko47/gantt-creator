## Design decisions (behavioural)

- **D1 — Validate count, bounds, and type.** The returned
  `ShapeRange` must be non-null, non-empty (count ≥ 1), with
  non-zero bounds, and the pasted entity must be the expected group
  shape; each violation is a distinct typed failure (**positive
  test** per violation via fakes).
- **D2 — Success is the validated result.** The stage's success
  output carries the validated facts (count, bounds) forward — R7.4
  positions the validated group; nothing downstream re-queries
  PowerPoint state it can avoid.
- **D3 — Non-throwing is not success.** A return without a valid
  `ShapeRange` is a failure even when no exception was thrown (the
  AGENTS.md rule, positively tested).

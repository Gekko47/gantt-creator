# R0.1 — Governance kit and repo scaffolding

> Block 0, R0.1 from `docs/03-ROADMAP.md`.

## Outcome

A new contributor can clone the repository, read `docs/STATUS.md` and `docs/REVIEW-CHECKLIST.md`, and understand the always-on agent contract, the current work item, and the gates a PR must clear.

## Scope

- `docs/` — the seven rule mirrors at their declared paths.
- `docs/work-items/TEMPLATE.md` — the work-item template.
- `docs/DECISIONS.md`, `docs/STATUS.md`, `docs/KNOWN-LIMITATIONS.md`, `docs/REVIEW-CHECKLIST.md` — control records.
- `docs/adr/0000..0003` — the four ADRs that this commit records.
- `.clinerules/*` and `AGENTS.md` — canonical, committed sources.
- `scripts/` — empty placeholder; populated by R0.6.

## Exclusions

- No `global.json`, no `Directory.Build.props`, no `Directory.Packages.props`, no solution, no projects. Those land in R0.2 and R0.3 with a real `dotnet build` gate.
- No `.github/copilot-instructions.md` or `.github/prompts/*.prompt.md` yet. Those land in R0.1's follow-up.
- No `.editorconfig` or analyzers — R0.4.

## Acceptance tests

- **Automated**: `pwsh -NoProfile -Command "Get-ChildItem docs -Recurse -File | ForEach-Object { if ($_.Name -notmatch '\.md$') { throw ('non-markdown file in docs: ' + $_.FullName) } }"` exits 0.
- **Visual Studio / Office**: None. This work item is pure documentation.

## Evidence commands

```powershell
# Files committed
git ls-files docs .clinerules AGENTS.md
# Markdown link sanity
pwsh -NoProfile -Command "Get-ChildItem docs, .clinerules, AGENTS.md -Recurse -File -Filter *.md | ForEach-Object { Get-Content -Raw $_.FullName | Select-String -Pattern '\]\((?!https?://|#)([^)]+)\)' -AllMatches | ForEach-Object { if (-not (Test-Path (Join-Path $_.DirectoryName $_.Matches[1].Groups[1].Value))) { Write-Warning ('broken link in ' + $_.FullName + ' -> ' + $_.Matches[1].Groups[1].Value) } } }"
```

## Risk and rollback

Risk: a future contributor edits `docs/` but not `.clinerules/`, drifting the two. Mitigation: a link-equality check in R0.6's verify script. Rollback: `git revert <commit>`.

## Design decisions (behavioural)

- **D1 — Idempotence is the contract.** A second repair run on an
  already-repaired workbook performs **zero mutations** (the
  observed-operation set is empty — **positive test**), mirroring
  R4.7's unchanged-scene pin.
- **D2 — Sentinels are untouchable.** Unowned shapes (with or without
  chart-like names) and user cells are asserted unchanged across every
  repair path (**positive test** with a hostile sentinel named like a
  chart shape but never tagged).
- **D3 — Deterministic duplicate resolution.** When two shapes claim
  one scene ID, the survivor is chosen by a deterministic rule
  (documented: e.g. the tagged-and-correctly-named one; ties by
  creation order) — recorded, never arbitrary.
- **D4 — Missing marks are reported, not fixed.** An untagged shape
  cannot be proven owned; repair reports it for the user and leaves it
  alone (deleting would violate the unowned-content invariant).

## Acceptance tests

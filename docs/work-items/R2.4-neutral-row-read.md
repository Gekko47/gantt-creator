# Work item — R2.4

## Outcome

Bulk-read every body row of `tblGanttData` into immutable, culture-invariant neutral `GanttRowDto`s via a single `Range.Value2` read plus the workbook `Date1904` flag. Identical serials read identically under GB (`DD/MM/YYYY`) and US (`MM/DD/YYYY`) display formats. 1904 workbooks are explicitly refused (ADR-0006). No validation, no rendering, no cell mutation.

### Decisions recorded here

- **D1 — Bulk `Value2`, never `.Text`.** One `DataBodyRange.Value2` read into `object[,]`. `.Text` is locale display text; `Value2` is locale-invariant (`double` dates, `string`/`double`/`bool` otherwise). Empty table (`DataBodyRange is null`) → `Ok([])`.
- **D2 — Header-name mapping, Ordinal.** `ListColumns[i].Name` → schema index via `GanttTableSchema.Default.TryGetColumn` (Ordinal). Tolerates column reorder; missing required header → `TableMissing`.
- **D3 — Converter lives in Core, takes primitives.** `TryConvertDate(object?, out DateOnly?)` etc. Core never references COM; Office passes `Value2` cells only. Keeps Core testable without Office and `CoreBoundaryTests` green.
- **D4 — Blank/error semantics (U4).** Blank (`null`/empty/whitespace text; `null` dates) → `null` DTO field; R2.5 decides requiredness. Excel error cells surface as `int` in `Value2` → `null` field, row preserved, no throw.
- **D5 — Trimming without rewriting.** Text cells `Trim()`ed, Ordinal, no case-folding (mirrors R2.1 D4 / R2.3 D2). Original cell untouched.
- **D6 — COM ownership (R2.2 precedent).** One proxy per local, no chained expressions, `for`-index loops (no `foreach` on COM collections), no `FinalReleaseComObject` on shared roots, STA thread only, `internal virtual` seams for every indexer (CS0855).
- **D7 — 1904 rejected (U1).** `Workbook.Date1904 == true` → `DateSystemUnsupported` before touching the table. See ADR-0006. Schema stays v1.
- **D8 — GB pinned, US as contrast (U2).** Live test Format A = GB `DD/MM/YYYY`, Format B = US `MM/DD/YYYY`; identical DTOs both ways proves no `.Text` parsing.

## Exclusions

- Domain validation/all-errors mapping (R2.5): unknown Type, duplicate/missing IDs, reversed/missing dates, colour/label capability checks, `Custom Activity` style-key requirement, clipping.
- Row error reporting/UI, any cell mutation (R2.6).
- Settings/style/metric tables, save/reopen (R2.7); add-row commands (R2.8); `tblGanttTypes` materialisation, dropdown (R2.9); repair/migration (R2.10).
- Scene/geometry/rendering (R3+), Ribbon, PowerPoint, PNG, new NuGet packages, schema-version bump.

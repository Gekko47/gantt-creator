## Design decisions

- **D1 — Line geometry (§24).** Vertical `SceneLine` at
  `x = DateToX(Start)`, `PlotBounds.Top` → `PlotBounds.Bottom` (never
  through title/data/header bands — bounds from R3.5); width
  `DelineatorLinePt`; z-layer 25; ID `<rowId>:delineator`.
- **D2 — Range policy.** Dates inside or on the inclusive range render
  (edges at the exact edge X); outside emits no line + one warning
  (shared point-event policy).
- **D3 — Labels.** Corner boxes offset `LabelGapPt` at the four plot
  corners, contained within chart bounds; Auto order TopRight →
  TopLeft → BottomRight → BottomLeft; `None` emits no text; delineator
  labels rank last in §22's priority; z-layer 75; ID
  `<rowId>:delineator-label`; near-date collisions use normal planner
  checks and may flip side.
- **D4 — Same-date rules.** Identical date + identical resolved line
  style → **one** line (both owners recorded in ownership metadata);
  same date + distinct labels → deterministic `StackGapPt` stack
  (lane/stack/sort/ID order).
- **D5 — Ignored fields.** `Finish`/`LaneId`/`StackIndex` are never
  read for geometry (R2.5's `NotUsedByType` owns the data-side notice).

# R0.8 — Versioning and local rolling-log abstractions

> Block 0, R0.8 from `docs/03-ROADMAP.md`. Builds on R0.7 (Windows CI for restore, format, build, unit tests, and artifacts).

## Outcome

The add-in has a deterministic version string sourced from Git at build time, a local rolling-log abstraction that redacts privacy-sensitive data by default, and the two tooling gaps L6 (workflow lint) and L7 (PowerShell script tests) are closed.

## Scope

**Production code (Core, net10.0):**
- `src/GanttCreator.Core/VersionInfo.cs` — version string from `git describe` + fallback, plus `AssemblyInformationalVersion`
- `src/GanttCreator.Core/Logging/IRedactor.cs` — redaction interface
- `src/GanttCreator.Core/Logging/Redactor.cs` — default redaction implementation (emails, paths, dates, tokens)
- `src/GanttCreator.Core/Logging/IRollingLog.cs` — rolling log interface (size-based rotation, count)
- `src/GanttCreator.Core/Logging/RollingLog.cs` — file-based rolling log with redaction injection

**Tests (Core.Tests, net10.0):**
- `tests/GanttCreator.Core.Tests/VersionInfoTests.cs` — version string format, fallback behaviour
- `tests/GanttCreator.Core.Tests/RedactorTests.cs` — redaction patterns (email, path, date, GUID, hex token)
- `tests/GanttCreator.Core.Tests/RollingLogTests.cs` — rotation at size boundary, file count cap, redaction injection

**Tooling — L6 (workflow lint):**
- `scripts/lint-ci.ps1` — invokes pinned `actionlint` binary against `.github/workflows/ci.yml`
- CI workflow step runs `pwsh -NoProfile -File scripts/lint-ci.ps1` with `LASTEXITCODE` check

**Tooling — L7 (Pester for scripts/):**
- `scripts/` gets Pester 5+ unit tests for each `.ps1` file under `scripts/` (exclude `_artifacts/`)
- `scripts/test-scripts.ps1` — invokes Pester with `-PassThru`, aggregates exit code
- `verify-quick.ps1` gets a new step: `scripts/test-scripts.ps1`

**CI updates:**
- `ci.yml` adds a `Script lint (Pester)` step
- `ci.yml` adds a `Workflow lint (actionlint)` step
- `setup-dotnet` already pins `10.0.x`; add a `actionlint` install step with pinned version

**Documentation:**
- Update `docs/KNOWN-LIMITATIONS.md` — close L6 and L7
- `docs/03-ROADMAP.md` — R0.8 exit demonstration updated

## Exclusions

- No new Office, Excel-DNA, SkiaSharp, clipboard, WinForms, or Drawing dependencies in Core.
- No telemetry, web font, cloud API, online licence check, or hidden network fallback.
- The rolling log is local-file only; no ETW, no EventSource, no Serilog/Log4Net.
- L6 uses a standalone `actionlint` binary (no Node/npm in CI).
- L7 uses Pester 5+ already present on the runner (`Get-Module -ListAvailable Pester` shows 3.4.0; we install Pester 5 in CI).

## Risk and rollback

Risk: Version string injected via MSBuild may differ between local and CI if Git history depth differs. Mitigation: `fetch-depth: 0` in checkout (already present in CI). Fallback version `0.0.0-local` is deterministic.

Rollback: `git revert <commit>` removes the new Core files, the scripts, and the CI steps; no product code is touched.

# Work item — R5.6b

> **Guide status**: Authored (Tier B — binding contract) 2026-09-25
> **Depends on**: R2.7 (versioned settings), R2.10 (explicit repair), R5.6 (shared settings-dialog infrastructure), R4.9 (Refresh).
> **Upgrade rule**: Re-verify exact dialog and Ribbon APIs against landed Phase 4/5 code before implementation.
> **ADR-0043 (implemented)**: the live chart title is an owned textbox shape (`PrimitiveId: "ChartTitle"`, `ZLayer.Frame`) created/updated/deleted by Refresh through `IShapeWritePort` + `ShapeReconciler`, driven by `ChartTitle`/`ShowTitle` settings. The cell-placeholder title write was removed from `ExcelWorkbookInitialiser`.

## Outcome

An approved Chart settings dialog lets the user update the workbook title and toggle title visibility. `ChartTitle` is nonblank, `ShowTitle` is the only title-band visibility control, both settings persist through save/reopen, and the generated chart changes only after explicit Refresh. The title is rendered as an owned textbox shape by Refresh (ADR-0043), not as a cell placeholder.

## Governing contracts

- `docs/07-GANTT-ENTITY-GUIDE.md` §2 — initial default `Gantt Chart`; populated band iff `ShowTitle=true`; no blank visible title.
- ADR-0014 — schema-v2 title/period settings contract.
- ADR-0007 D4 and ADR-0011 — only approved dialogs write settings; repair remains explicit.
- ADR-0043 — live title is an owned textbox shape created by Refresh; settings drive shape text/visibility.
- Refresh-only rendering: setting changes never mutate generated shapes directly. The title shape is created by Refresh, not by the dialog.

## Scope

- Core — nonblank title validation and an exact two-setting write request.
- Office — guard-first bulk update of only `ChartTitle` and `ShowTitle` in `tblGanttSettings`. Refresh creates/updates/deletes the owned title textbox shape.
- AddIn — Chart settings dialog (`ChartTitleForm`) and Ribbon entry point, reusing landed R5.6 infrastructure where compatible. `ChartTitle`/`ShowTitle` settings are read at Refresh time and the title textbox is reconciled alongside scene primitives.
- Core, Office contract, AddIn, and live Office tests.

## Exclusions

- No period-label-format UI; that belongs to the R5.2 scale/layout controls.
- No data-panel or style edits (R5.6).
- No render on dialog confirmation; the user must run Refresh. The title shape is created by Refresh.

## Acceptance

- Cancelling writes nothing.
- Blank/whitespace title is refused before mutation.
- Confirming writes exactly the two intended settings rows and preserves all other settings.
- User edits survive save/reopen.
- `ShowTitle=false` removes the band after Refresh; `ShowTitle=true` restores the retained title after Refresh.
- Editing a setting does not invoke the renderer; Refresh creates the title textbox from settings.
- Live Office evidence records the workbook/settings mutation set and both Refresh outcomes.

## Stop conditions

- A direct VeryHidden-sheet editor is proposed (settings writes go through `WriteSettings` only).
- A blank title can produce a visible empty band.
- Dialog confirmation would render without an explicit Refresh.

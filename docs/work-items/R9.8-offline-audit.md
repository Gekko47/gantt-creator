## Design decisions (behavioural)

- **D1 — The audit is mechanical and standing.** The network-API
  guard runs in every verify (not a one-off inspection) — a future
  dependency cannot quietly introduce networking.
- **D2 — Package claims are inspected, not trusted.** Each shipped
  package's network behaviour is checked (metadata/documentation
  evidence recorded); a package with hidden telemetry is a defect to
  route, not a note to file.
- **D3 — The disconnected run is the acceptance.** The run's results
  (every capability exercised offline, with host builds) are the
  exit evidence; any network attempt (host-level observation) fails
  the row.

## Acceptance tests

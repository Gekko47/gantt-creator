## Design decisions (behavioural)

- **D1 — One deterministic list.** The surface shows every
  scene-level warning grouped and ordered (severity → row → kind);
  repeated refreshes produce an identical list (determinism pin).
- **D2 — Complement, not duplicate.** Row-level issues that R2.6
  already notes are *summarised by count only* with a pointer to the
  notes; scene-level warnings get full entries. A contract test
  asserts no cell-note writes occur (**positive test**).
- **D3 — Read-only.** The surface mutates nothing (the live gate
  proves byte-identical `Value2` matrices around provoking each
  warning — the R2.6 discipline).
- **D4 — Refresh-coupled.** The list reflects the last Refresh's
  scene (stale lists are labelled with the refresh time; no
  live-revalidation on edit — refresh-only philosophy).

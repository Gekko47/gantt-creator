## Design decisions (behavioural)

- **D1 — Every visual token is verified, not assumed.** Each
  `imageMso` is confirmed against the MS Learn idMso table (the R2.6
  `Spelling` discipline); each keytip is unique; each control has
  label + screentip (+ supertip where the contract tests require).
- **D2 — Accessibility labels are contract-tested.** `getLabel`/
  `getScreentip` cover every control; the live gate exercises
  keyboard traversal (keytips), screen-reader labels, and
  high-contrast rendering.
- **D3 — Offline help only.** Supertip help points at local content;
  a contract test asserts no `http(s)` links anywhere in the ribbon
  resources (**positive test**).
- **D4 — The scope-check decision is a STOP-point.** The
  show/hide-columns control and in-cell validation for
  `StyleKey`/`LabelPosition` are not implemented here; the decision is
  recorded (either "defer to a later release" or an entity-guide
  amendment + row) before this row can claim completion.

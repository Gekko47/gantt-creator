## Outcome

`tblGanttData` carries a user-authored **`Activity ID`** column between `Type` and
`Description`, the ribbon's **Show columns** menu can hide and show it like the other visible

## Exclusions

- No migration. A pre-26 workbook reports the schema-version mismatch and the remedy is
  Initialise (ADR-0029 D6).
- No change to the engine-hidden `Id` column, `ParentId`, scene ownership, or outline planning.
- No format or duplicate-reference validation. `Activity ID` is free text; a rule for it would
  be a new validation code and is a separate work item.
- No new `tblGanttSettings` key, so the settings-to-config table anchor does not move.
- No new ribbon glyph, no per-column width policy, no change to `Duration` or the label
  controls.

## Risk and rollback

The panel gains one default-width column, so the plot origin moves right and the plot width
shrinks by that width; at a narrow size preset a very wide column can reach
`InsufficientPlotWidth`. Hiding the column restores the previous geometry through
`MeasuredColumnsFor`. Rollback is a normal revert of this work item's commits; no workbook
migration is involved because the version gate refuses old files either way.

## Definition of done

Acceptance tests pass; Release build with analyzers and `-warnaserror` is clean; no test was
weakened; the entity guide, architecture column list, `REPO-MAP` and `STATUS` are updated;
the one-sheet invariant is unchanged; a human ran the Office gate and recorded the Excel build.

## Notes during implementation

- **The first ribbon row id failed on the live host (2026-11-17).** `colActivity ID` was
  rejected while loading the Custom UI: RibbonX `id` is `ST_UniqueID`, which forbids a space.
  The row id is now `col` + `GanttColumnVisibility.RibbonItemId(name)`, so `Activity ID`
  becomes `colActivityID`; the header and the cell text remain `Activity ID`, and
  `TryResolveRibbonItemId` is the inverse the callbacks use. A Core fact pins every derived
  id as space-free and unique.
- Visible columns take 60pt on Initialise (owner ruling 2026-11-17) through
  `GanttTableAppearance.DefaultVisibleColumnWidthPt`, applied with the same bounded
  characters-to-points correction the gutter uses; a rebuilt sheet gets it, a Repair over an
  existing table does not. `VisibleColumnWidthTests` pins the visible-only rule and the
  no-write case.
- `PlotAnchorColumnIndex` is derived from the column count, so the anchor moves from `S` to
  `T` with no code change; the stored defined name is rewritten by Initialise or Repair and
  the integrity checker reports a disagreement until then.

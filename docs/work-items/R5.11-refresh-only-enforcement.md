## Design decisions (behavioural)

- **D1 — Provable non-invocation.** The tests observe the renderer
  through a counting seam (contract fakes record invocations); every
  edit path asserts the count is zero — a positive proof, not an
  absence of tests.
- **D2 — Blocking Refresh preserves the last scene.** A rendered
  chart + blocking validation errors → Refresh → owned shapes
  byte-identical (IDs/counts/bounds, the R4.7 discipline); errors
  surfaced per R4.9/R5.8.
- **D3 — Exit evidence.** Run the exit demonstration on the reference
  machine (host builds recorded); upgrade the Phase-6 guides to
  Tier A with refresh dates; update the manifest tiers. Phase 5 adds
  no new matrix rows — the applicable Phase-4 subset rows are
  re-confirmed where the demonstration touches them.

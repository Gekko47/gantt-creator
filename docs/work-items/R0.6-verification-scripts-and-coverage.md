# R0.6 — Quick/full verification scripts and coverage settings

> Block 0, R0.6 from `docs/03-ROADMAP.md`. Builds on R0.5 (sample tests
> and OfficeIntegration trait).

## Outcome

`verify-quick.ps1` and `verify.ps1` gates run locally and predict CI
behaviour. `verify-quick.ps1` runs restore, format, Release build, and
the non-Office test suite. `verify.ps1` adds markdown link sanity,
coverage collection with per-project thresholds, package vulnerability
scan, and working-tree hygiene. `verify-office.ps1` runs only the
`OfficeIntegration` xUnit trait on the self-hosted runner.

## Scope

- `scripts/verify-quick.ps1` — restore, build Release `-warnaserror`,
  test with `OfficeIntegration` excluded. Runs on every commit.
- `scripts/verify.ps1` — all quick gates plus markdown link sanity
  (`scripts/check-md-links.ps1`), coverage collection with per-project
  thresholds (enforcement deferred to R3.x per
  `docs/04-TEST-STRATEGY.md`), package vulnerability scan
  (`dotnet list package --vulnerable --include-transitive`), and
  working-tree hygiene check (`git status --short`).
- `scripts/verify-office.ps1` — runs only the `OfficeIntegration` xUnit
  trait on the self-hosted runner per `docs/adr/0001`.
- Coverage thresholds defined in `verify.ps1` per-project:
  - `GanttCreator.Core`: line >= 95%, branch >= 90%
  - `GanttCreator.Raster`: line >= 90%, branch >= 85%
  - `GanttCreator.Office`: line >= 80%, branch >= 70%
  - `GanttCreator.AddIn`: line >= 75%, branch >= 65%

## Exclusions

- No workflow lint (actionlint) — that is L6/R0.8.
- No Pester script tests — those are L7/R0.8.
- No coverage enforcement — thresholds are reported but not enforced
  until R3.x per `docs/04-TEST-STRATEGY.md`.
- No CI workflow — that is R0.7.
- No golden-image tests — those are R8.x.

## Acceptance tests

- **Automated**:
  - `pwsh ./scripts/verify-quick.ps1` → exit 0.
  - `pwsh ./scripts/verify.ps1` → exit 0.
  - `dotnet test GanttCreator.slnx -c Release --filter
    'Category!=OfficeIntegration'` → all tests pass.
  - `pwsh ./scripts/verify-office.ps1` → runs only the
    `OfficeIntegration` trait (not run here; requires desktop Office on
    the self-hosted runner).

## Evidence commands

```powershell
# 1. Quick gate (every commit)
pwsh -NoProfile -File scripts/verify-quick.ps1

# 2. Full gate (before PR)
pwsh -NoProfile -File scripts/verify.ps1

# 3. Non-Office test suite
dotnet test GanttCreator.slnx -c Release --filter 'Category!=OfficeIntegration'

# 4. Office integration suite (self-hosted runner only)
pwsh -NoProfile -File scripts/verify-office.ps1
```

## Risk and rollback

Risk: CI environment differences (SDK patch band, runner cache) make a
step fail locally-green code. Mitigation: `setup-dotnet` selects the
latest installed `10.0.x` patch and `global.json` uses `rollForward:
latestFeature`; every command in `verify-quick.ps1` is verbatim from
the local gate that passes. Rollback: `git revert <commit>` removes the
scripts; no product code is touched.

## Definition of done

- `scripts/verify-quick.ps1`, `scripts/verify.ps1`, and
  `scripts/verify-office.ps1` exist and are committed.
- Both quick and full gates pass locally.
- Per-project coverage thresholds are defined and reported.
- `docs/STATUS.md` records R0.6 as done.

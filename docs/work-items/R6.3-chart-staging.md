## Design decisions (behavioural)

- **D1 — One translation, once.** Each primitive's points translate
  to the staging origin by a single vector (add origin; snap once at
  the R4.3 boundary); no per-primitive scaling or re-layout.
- **D2 — Bounds equality is the contract.** The composed set's
  bounding box equals the R6.1 export bounds within
  `GeometryMath.Epsilon` (the documented tolerance); a shape outside
  the bounds fails the test (**positive test** with a stray-shape
  fixture).
- **D3 — View discipline.** Staging never scrolls/activates corrupts
  the user's view: view state (scroll, zoom, selection) is captured
  and restored around the operation (the R4.2 scope); the live gate
  proves real content and view survive.

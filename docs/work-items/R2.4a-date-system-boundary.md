## Outcome

Isolate Excel date-system support/refusal behind an Office-free converter while keeping ADR-0006's 1904 rejection.

## Scope

- New Core date-system kind, converter contract, and 1900 implementation.
- `ExcelCellConverter.cs` and `ExcelGanttTableReader.cs` delegate conversion.
- Core unit tests, Office contract tests, and existing 1904 live integration test.

## Decisions

The reader asks the converter for support before table access. Windows 1900 is supported; Mac 1904 is unsupported. No 1904 offset is implemented. Date strings remain forbidden. Serial 60 remains pinned.

Checklist: A, F, G, I. Office gate: Required.

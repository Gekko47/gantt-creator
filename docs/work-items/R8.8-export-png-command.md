## Design decisions (behavioural)

- **D1 — One command, the verified pipeline.** ExportSize →
  render (R8.4 path) → encode+metadata (R8.5) → atomic write +
  validate (R8.6) → success only after validation; typed failures →
  one actionable message each; success states the written path +
  exact dimensions (counts/sizes only — no schedule content).
- **D2 — Independent verification.** The test's assertions about
  dims/density/crop/aspect come from an independent re-read of the
  file bytes (a separate minimal parser in the tests), not from the
  writer's return values — the "independently verify" wording.
- **D3 — Exact crop.** The image contains exactly the scene bounds
  (R6.1/R3.5 geometry) — no whitespace: an edge-pixel probe asserts
  the first/last rows/columns carry the chart background/frame, not
  empty margin (**positive test** on a fixture with known edges).
- **D4 — Exit evidence.** The all-unit live demonstration recorded
  with host builds; the matrix subset completed; the Phase-9 guides
  upgraded to Tier A with refresh dates; manifest tiers updated.

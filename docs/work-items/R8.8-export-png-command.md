## Outcome

The **Export PNG** command renders the exact scene crop at the chart's own
size — the export composition's bounds at 300 DPI — and delivers it to the
user's selected target: the clipboard by default, a verified file on the
split button's menu. Dimensions, density, crop, and aspect are independently
inspected. A first export after opening needs no manual refresh: the command
runs the explicit-refresh pipeline itself only when the workbook has not
rendered since it was opened. Before any target action it identifies font
compatibility through the pinned resolver and falls back to the pinned-font
raster render with a reported substitution. The Phase-8 exit evidence uses
the revised demonstration below.

## Design decisions (behavioural)

- **D1 — One command, the verified pipeline.** ExportSize →
  render (R8.4 path) → encode+metadata (R8.5) → atomic write +
  validate (R8.6) → success only after validation; typed failures →
  one actionable message each; success states the written path +
  exact dimensions (counts/sizes only — no schedule content).
- **D2 — Independent verification.** The test's assertions about
  dims/density/crop/aspect come from an independent re-read of the
  file bytes (a separate minimal parser in the tests), not from the
  writer's return values — the "independently verify" wording.
- **D3 — Exact crop.** The image contains exactly the scene bounds
  (R6.1/R3.5 geometry) — no whitespace: an edge-pixel probe asserts
  the first/last rows/columns carry the chart background/frame, not
  empty margin (**positive test** on a fixture with known edges).
- **D4 — Exit evidence.** The all-unit live demonstration recorded
  with host builds; the matrix subset completed (including R8.6's
  owed live unwritable-path case, discharged here); the Phase-9
  guides upgraded to Tier A with refresh dates; manifest tiers
  updated.
- **D5 — The scene is the shared export composition** (review,
  2026-11-22). The command consumes `EditableExportPreflight`
  unchanged: the resolver pins the `EditableExport` profile and
  rides the scene on the outcome, and `SceneBuilder` treats every
  non-live profile identically, so the editable-export scene **is**
  the raster scene — proven by R8.4's profile-equivalence fact, not
  re-derived here. Re-labelling the pipeline to
  `SceneCompositionProfile.Raster` would change the resolver's
  documented pin for no behavioural gain.
- **D6 — The render is synchronous on Excel's command thread**
  (review F7, 2026-11-22). Typical widths cost ~3–10M pixels; the
  `MaxTotalPixels` budget bounds the legal worst case (~400 MB
  frame). Cancellation/deadline for long non-COM rendering is
  R9.1's row — Phase 8 records the accepted synchronous behaviour
  rather than inventing threading, so the freeze risk is a recorded
  trade, not a surprise.

### Revision 2026-11-23 decisions (D7–D10, owner ruling)

D1's width-parse stage is replaced by D7; D2–D6 stand where they do not
conflict with the new targets.

- **D7 — Size is the chart's own.** The pixel dimensions come from the
  pre-flight's fresh export-composition bounds in points at 300 DPI
  (`round(pt / 72 * 300)` per axis, the `ExportSize` limits and
  single-rounding rule). No width input, no cached aspect: a table changed
  since the last render can never size the image for a chart that no longer
  exists. The R8.4 goldens' recorded dimensions are reproduced exactly.
- **D8 — Clipboard first; the file target is a verified write.** The main
  button places the rendered image on the clipboard and the status bar
  reports success; the split button's menu toggles the main action to a
  verified file write. The target is the persisted `PngExportTarget`
  setting (default `clipboard`, schema 28; ADR-0007 D3 amendment). The
  clipboard is verified by reading its formats back — a non-throwing
  placement is never success (the R6.6 discipline).
- **D9 — The file dialog defaults to the workbook's folder and remembers
  the choice.** Initial directory: the `LastPngExportFolder` setting when it
  names an existing folder, else the workbook's own folder, else the dialog
  default for an unsaved workbook. A successful write persists the chosen
  folder; a cancelled dialog remembers nothing and stays the silent
  `Cancelled` outcome.
- **D10 — Freshness is ensured, never demanded; fonts are identified with an
  approved fallback.** The button is gated on the same state as Copy
  Editable (Ready + active Gantt sheet). The command checks the
  chart-current flag (a completed refresh has run since the workbook state
  last changed) and, when false, runs the explicit-refresh pipeline through
  its existing entry with presentation suppressed — never a second refresh
  implementation. Before any target action the command resolves the scene's
  text families through `PinnedFontSource`; an unresolvable family while the
  pinned faces load renders a substituted scene (the label family replaced
  by the pinned family through the validated `SceneStyle` constructor) and
  reports the substitution in the status bar and the technical record; the
  missing-pinned-set case remains the typed refusal (ADR-0070 D3
  amendment).

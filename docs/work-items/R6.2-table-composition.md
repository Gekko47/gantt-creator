> **Guide status**: Authored (Tier B — binding contract) 2026-09-21 ·

## Outcome

The selected table/header cells compose as native rectangle/text
shapes at the staging origin — reproducing exactly the R3.11 panel
primitives (backgrounds, texts, shared borders) — pinned by shape
count, bounds, cell text, style, and z-order contract tests and a
live staged-composition inspection.

## Context and owed deferrals

Roadmap row: *Compose table/header cells as native rectangle/text
shapes — Shape count, bounds, cell text, style, and z-order contract
tests — Required: inspect a real staged table composition in Excel.*

The architecture's premise: "The editable export must contain no live
cells because PowerPoint cannot preserve cell ranges and shapes as
one reliably editable shape group."

## Exclusions

- No chart entities (R6.3 stages the full scene incl. bars/markers/
  delineators/bands); no grouping (R6.4); no clipboard (R6.6); no
  cell writes or sheet additions ever (the staging rule).

## Design decisions (behavioural)

- **D1 — Scene-driven, cell-free.** Every composed shape comes from a
  scene primitive; zero live cells are included; a contract test
  asserts zero cell writes and zero sheet additions (**positive
  test**).
- **D2 — Exact reproduction.** Shape count = the panel primitive
  count; bounds = primitive bounds (within the documented tolerance);
  texts verbatim; styles from the token mapping (R4.6); z-order per
  the scene (R4.5's one-pass rule).
- **D3 — Temporary + owned from birth.** Every staged shape carries
  the temporary/owned marking (the R4.3 tag mechanism + the staging
  lifecycle's collection contract — R6.5 owns the lifecycle, this row
  registers into it).

## Acceptance tests

## Stop conditions (item-specific)

- Composition would need to read worksheet cells directly → stop
  (scene is the source; measured bounds entered the scene in Phase 4).
- A live cell would remain in the export → stop (the architecture's
  premise).

## Risk and rollback

Main risk: primitive-count drift when R3.11 changes — pins fail
loudly; update together. Rollback: `git revert`.

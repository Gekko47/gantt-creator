## Design decisions (behavioural)

- **D1 — Success message states what was verified.** "Copied the
  editable Gantt (N shapes) to the clipboard" — count-only, and
  truthful only because R6.6 verified the format first; failure
  messages map each typed refusal to one actionable line (no schedule
  content).
- **D2 — One command, one state scope.** The whole pipeline runs
  inside the R4.2 scope; the R6.5 `finally` cleanup is the inner
  guarantee; unexpected exceptions cross the one boundary.
- **D3 — The Office gate is the exit demonstration.** One click →
  manual paste to Excel and to PowerPoint → ungroup/edit children →
  confirm zero staging residue (shapes and worksheets); then the
  matrix subset (slide sizes; clipboard-unavailable and
  PowerPoint-absent/busy failures — the latter exercised as far as a
  clipboard-only row can, with the Phase-7 rows completing them);
  then the Phase-7 guide upgrade.

## Implementation record

Status: **implemented 2026-11-19; the manual exit demonstration is owed.**

- `CopyEditableCommand` (AddIn) owns the pipeline order: read → validate →
  configuration → measurement → export request → the `ExportIncludeDataPanel`
  selection → bounds → `StagingLifecycle.Run` (compose, group, verified copy,
  cleanup inside the R4.2 scope). The export-request build, the bounds resolve
  and the lifecycle invocation ride delegate seams (`ExportRequestBuild`,
  `ExportBoundsResolve`, `StagingLifecycleRun` — the R6.5 copy-seam precedent)
  so `CopyEditableCommandTests` pins the order without a host.
- **The owner's 2026-11-19 ruling is implemented as the fallback it
  authorises.** "Copy as-is, errors included" is not expressible through the
  landed pipeline (the export scene is built from validated events and a
  blocking-error row has no defined chart geometry), so the copy proceeds with
  the valid rows and names the omission: "M row(s) with errors were not copied
  — fix them and copy again", plus one technical record. An all-invalid table
  refuses through the existing typed refusals. An errors-included panel
  reproduction is an owed deferral for a future Core-contract ADR. No repairs
  run on copy (D9-6).
- **Presentation.** The D1 sentence is
  "Copied the editable Gantt (N shapes) to the clipboard." with N = the staged
  child count (singular "shape" at 1); the status bar carries it, and a
  `DisplayStatusBar = false` user gets the dialog instead (D9-5, via the new
  `IExcelApplicationAdapter.IsStatusBarVisible`). Every typed refusal maps to
  one actionable line; `EmptyVisibleTable` is Core's sentence verbatim; the
  copy refusal reuses the R6.6 stage's own detail. Presenters degrade.
- **The Export group is created** (`grpExport` between Sheet and Diagnostics)
  with `btnCopyEditable` as its only member — R5.16b active-sheet gate,
  fail-closed visibility, thin-boundary callback, keytip/screentip/supertip,
  and a generated Lucide `copy-editable` glyph. Send to PowerPoint (R7.6) and
  the PNG controls (R8.7/R8.8) are left unstubbed.
- **Evidence (observed 2026-11-19).** `dotnet test` AddIn **836/836**

## Design decisions (behavioural)

- **D1 — Success message states what was verified.** "Copied the
  editable Gantt (N shapes) to the clipboard" — count-only, and
  truthful only because R6.6 verified the format first; failure
  messages map each typed refusal to one actionable line (no schedule
  content).
- **D2 — One command, one state scope.** The whole pipeline runs
  inside the R4.2 scope; the R6.5 `finally` cleanup is the inner
  guarantee; unexpected exceptions cross the one boundary.
- **D3 — The Office gate is the exit demonstration.** One click →
  manual paste to Excel and to PowerPoint → ungroup/edit children →
  confirm zero staging residue (shapes and worksheets); then the
  matrix subset (slide sizes; clipboard-unavailable and
  PowerPoint-absent/busy failures — the latter exercised as far as a
  clipboard-only row can, with the Phase-7 rows completing them);
  then the Phase-7 guide upgrade.
